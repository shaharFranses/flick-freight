# Art swap map: old look → "Morning Hybrid"

Every visible item in the game, where it lives, and whether it is in the new look
(`docs/FlickFreight_Art_Style_Guide.pdf`). Status as of branch `art-v3-full`.

**How the new look is applied**

- **PNG slots** in `art/v3/` are picked up by `scripts/art/assets.gd` (`ArtAssets`). A missing file
  falls back to the old look, so a wrong file name fails quietly.
- **Code-drawn items** (vehicles, moving obstacles, static obstacles) use one drawing kit,
  `scripts/art/draw_kit.gd` (`ArtDraw`), and only colours from `scripts/art/palette.gd` (`ArtPalette`).
- Art changes are **visual only**. No collision shape, level data or physics constant was changed.

**One deliberate difference from the style guide:** the guide says "one red truck, no other
vehicles". Shahar decided to keep the 10 special vehicles and redraw them in the new style, each
with its own colour. The V0 truck is still the only red one.

## 4. Adding or changing art

- New code-drawn item: draw it with `ArtDraw` (`ink_rect`, `ink_poly`, `panel`, `wheel`, `cab`,
  `hazard`, `bed_wall`) and add any new colour to `ArtPalette` first.
- New background: add a function to `tools/art/make_bg.py`, run it, then run
  `godot --headless --import` so the `.import` file is written.
- Check every change at 1280×720 and 800×450, in colour and greyscale (guide page 16).
